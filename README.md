# SiteManager Mobile

Приложение для Android с той же базой, что и ПК-версия SiteManager.
Данные синхронизируются через Яндекс Диск.

## Сборка APK (GitHub Actions)

1. Заведите репозиторий на GitHub (бесплатный аккаунт).
2. Загрузите в него файлы: `main.py`, `store.py`, `ydsync.py`, `buildozer.spec`,
   папку `.github/workflows/apk.yml`.
3. Откройте вкладку **Actions** — сборка запустится сама. Первая занимает 30–60 минут.
4. Когда сборка позеленеет, скачайте артефакт **sitemanager-apk** — внутри `sitemanager-*.apk`.
5. Скопируйте APK на планшет и установите (разрешите установку из неизвестных источников).

## Настройка синхронизации

1. **Яндекс Диск**: загрузите в корень Диска папку `SiteManager` с файлом
   `sitemanager.db` и папками `PDF`, `Заявки`, `Записки`, `КС2` (как у вас на ПК).
2. На [id.yandex.ru](https://id.yandex.ru) → Безопасность → Пароли приложений →
   создайте пароль для приложения с доступом к файлам Диска.
3. В приложении: **Синхронизация** → введите логин Яндекса и этот пароль → «Сохранить».
4. **⟳ Загрузить** — база и файлы с Диска появятся на планшете.
   После работы на планшете — **↑ Отправить**, и на ПК клиент Диска подтянет изменения.

## Правило синхронизации

SQLite не поддерживает одновременную запись с двух устройств: в один момент
работайте на одном устройстве — планшете **или** ноутбуке. Приложение следит
за конфликтами и предупреждает, если облачная база старше локальной.

## Что есть на планшете

- Объекты → проекты → спецификация (просмотр и правка ячеек) и PDF-версии.
- Чек-лист: обе роли (Инженер СС / Инженер АДИС), недели, статусы, проценты,
  даты, проблемы, комментарии — данные совместимы с ПК-версией.
- Заявки: список, позиции, смена статусов тапом.
- Подрядчики → КС-2: пятиколоночный список (№, дата, период, разделы) и карточка акта.
- Склад: поиск, отправка на объект (с записью перемещения).
- Записки, глобальный поиск, PIN-код входа.
- Смета — только на ПК.

## Известные ограничения первой версии

- PDF открывается системным просмотрщиком; если на вашем планшете это не сработает —
  поправим в следующей итерации (FileProvider уже заложен, нужен тест).
- Загрузка КС-2 и PDF с планшета (через камеру/файлы) — следующая итерация.
